# Ego Audio Editor

Run EgoAudioEditor.exe on Windows x64. Keep the license folder beside the executable.

Open audio files or folders, preview sounds, export WAV, and import WAV or compatible WEM replacements. Export to Mod creates a Simplified Launcher ZIP and a companion .egoaudio project.

Replacement WAVs must use PCM16 with the original sample rate and channel count. Music editing requires matching metadata.bnk and companion streams. Original files are preserved.
